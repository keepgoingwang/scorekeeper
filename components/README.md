# components 公共组件

存放可复用的自定义组件。按 `组件名/组件名.{js,wxml,wxss,json}` 四件套组织。

## 已有组件

| 组件 | 说明 |
| --- | --- |
| `empty-state` | 空状态占位（空列表、无数据） |
