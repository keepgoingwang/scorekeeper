## 二、产品概述

### 2.1 产品背景
线下打牌时，计分算账往往依赖纸笔或心算，容易出错、效率低、体验差。本小程序旨在提供一套**可视化、智能化、社交化**的计分工具，让计分过程像游戏一样轻松愉快。

### 2.2 产品目标
- 支持快速开房、扫码入房，降低使用门槛
- 提供两种计分模式（自动/手动），适配不同打牌习惯
- 以牌桌可视化布局替代传统列表，增强沉浸感
- 房间结算时自动判断胜负，无需人工计算

### 2.3 用户画像
- **主要用户**：20-50岁，经常线下打牌（麻将、扑克等）的社交群体
- **使用场景**：茶馆、棋牌室、家庭聚会等线下场景
- **核心痛点**：计分繁琐、算账易错、缺乏战绩记录

## 四、核心功能详解

### 4.1 首页

#### 4.1.1 页面布局
- **顶部**：产品Logo + 品牌标语（"打牌计分，轻松搞定"）
- **中部**：两个主要操作按钮
  - 「创建房间」—— 大号主按钮，绿色渐变
  - 「加入房间」—— 次按钮，支持扫码和输入房间号两种方式
- **底部**：历史战绩快捷入口 + Tab导航栏

#### 4.1.2 交互说明
- 点击「创建房间」→ 弹出房间配置弹窗（设置人数上限、计分模式）→ 进入房间页
- 点击「加入房间」→ 唤起相机扫码 或 弹出输入框输入6位房间号 → 验证后进入房间
- 历史战绩入口 → 跳转战绩页

#### 4.2.2 牌桌布局规则（关键创新点）

**规则1：人数 ≤ 4人**
- 使用**正方形牌桌**
- 4个玩家头像均匀分布在正方形四边
- 牌桌中央显示当前局数、总积分池
- 桌面皮肤可更换（默认：绿色麻将桌、蓝色扑克桌、木质复古桌等）

**规则2：人数 ≥ 5人**
- 使用**圆形牌桌**
- 第一圈最多容纳**8个头像**，均匀分布在圆周上
- 若人数 > 8，第二圈头像在第一圈外侧，形成同心圆布局
- 头像大小随人数增加适当缩小，保持整体协调

**规则3：头像与筹码**
- 每个玩家头像下方显示：昵称 + 当前积分
- 头像前方（朝向牌桌中心方向）显示**筹码堆**
- 筹码数量与积分正相关：
  - 积分 > 0：筹码堆较高，颜色为金色/绿色
  - 积分 = 0：无筹码或少量筹码
  - 积分 < 0：筹码堆较低或显示负债标识（红色小图标）
- 筹码视觉为3D堆叠效果，积分越高堆得越高

**规则4：头像交互**
- 点击任意玩家头像 → 弹出该玩家操作菜单
  - 查看详情（积分变化历史）
  - 手动结算时：选择该玩家作为收款方
  - 踢出房间（房主权限）

#### 4.2.3 计分模式一：自动结算

**触发条件**：点击底部「自动结算」按钮

**操作流程**：
1. 弹出结算面板，显示当前房间内所有玩家列表
2. 每个玩家需要输入本局的**收入或支出金额**
3. 输入规则：
   - 收入填正数，支出填负数
   - 或提供「收入/支出」切换开关
4. 系统实时校验：所有玩家输入金额之和必须等于0（收支平衡校验）
5. 校验通过后，点击「确认结算」
6. 系统更新每位玩家的总积分，并重新计算筹码显示

**示例**：
```
玩家A（张三）：+100  （赢了100）
玩家B（李四）：-50   （输了50）
玩家C（王五）：-30   （输了30）
玩家D（赵六）：-20   （输了20）
─────────────────────
校验：100 + (-50) + (-30) + (-20) = 0 ✓
```

#### 4.2.4 计分模式二：手动结算（精确支付）

**触发条件**：点击底部「手动结算」按钮

**操作流程**：
1. 进入手动结算模式，界面提示："请点击付款方头像"
2. 用户点击付款方头像（积分减少的玩家）
3. 界面切换提示："请点击收款方头像"
4. 用户点击收款方头像（积分增加的玩家）
5. 弹出金额输入框，输入转账金额
6. 确认后，系统完成积分划转

**替代方案（列表式）**：
- 提供「切换列表视图」按钮
- 列表中显示所有玩家，付款方选择收款方，输入金额
- 适合不喜欢点击头像的用户

**交互细节**：
- 选择付款方时，该头像高亮显示（蓝色边框脉冲动画）
- 选择收款方时，两点之间出现虚线连接动画
- 金额输入使用数字键盘，最大支持4位数
- 支持多笔连续转账，无需重复进入模式

#### 4.2.5 房间结算（终局）

**触发条件**：点击底部「房间结算」按钮（房主权限）

**结算逻辑**：
1. 系统读取每位玩家的当前总积分
2. 判断规则：
   - 积分 > 0：显示「赢家」标签，绿色背景
   - 积分 = 0：显示「保本」标签，灰色背景
   - 积分 < 0：显示「输家」标签，红色背景
3. 生成结算报告：
   - 排名列表（按积分从高到低）
   - 每人盈亏明细
   - 建议转账方案（谁给谁转多少钱可以结清）
4. 提供「分享战绩」按钮，生成战绩卡片可分享至微信

**示例结算报告**：
```
🏆 房间结算报告 🏆
房间号：888888
总局数：12局

🥇 第一名：张三  +350分  [大赢家]
🥈 第二名：李四  +120分  [小赢]
🥉 第三名：王五   -80分  [小输]
    第四名：赵六  -200分  [大输]
    第五名：钱七  -190分  [大输]

💰 建议转账：
赵六 → 张三：200元
钱七 → 张三：150元
钱七 → 李四：40元
```

## 五、全局交互规范

### 5.1 页面转场
- 所有页面切换使用**滑动转场**（从右向左滑入）
- 返回使用反向滑动（从左向右滑出）
- 弹窗使用**底部上滑**或**中心缩放**动画

### 5.2 加载状态
- 页面加载：使用品牌色（薄荷绿）的脉冲圆点
- 数据提交：按钮变为加载态，显示旋转图标
- 网络异常：全屏提示 + 重试按钮

### 5.3 空状态
- 无历史战绩：显示空状态插画 + "还没有战绩哦，快去开一局吧~"
- 房间内无人：显示等待状态 + "等待牌友加入..."

### 5.4 手势操作
- 房间页左滑：快速查看上一局结算
- 房间页右滑：返回首页
- 长按头像：显示玩家详细信息浮层

## 六、视觉设计规范

### 6.1 设计理念
**"轻松、愉悦、社交"** —— 让计分过程像游戏一样有趣，降低算账的焦虑感。

### 6.2 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| **主色调** | `#4ECDC4`（薄荷绿） | 品牌主色，用于主按钮、选中状态、重要标识 |
| **辅助色** | `#45B7D1`（天空蓝） | 次要按钮、链接、信息提示 |
| **强调色** | `#FFD93D`（明黄色） | 筹码、赢家标识、重要数据高亮 |
| **成功色** | `#6BCB77`（草绿色） | 正向积分、成功提示 |
| **警告色** | `#FF9F45`（橙色） | 中等提示、待确认状态 |
| **危险色** | `#FF6B6B`（珊瑚红） | 负向积分、错误提示、输家标识 |
| **背景色** | `#F8FAFB`（浅灰白） | 页面背景，营造轻松氛围 |
| **卡片背景** | `#FFFFFF`（纯白） | 内容卡片、弹窗背景 |
| **牌桌绿** | `#2D5A3D`（深绿） | 默认牌桌颜色，经典麻将桌感 |
| **文字主色** | `#2C3E50`（深灰蓝） | 标题、重要文字 |
| **文字次色** | `#7F8C8D`（中灰） | 辅助说明、次要信息 |
| **分割线** | `#E8ECEF`（浅灰） | 列表分割线、边框 |

### 6.3 字体规范
- **标题**：PingFang SC Bold，18px，颜色 `#2C3E50`
- **正文**：PingFang SC Regular，14px，颜色 `#2C3E50`
- **辅助文字**：PingFang SC Regular，12px，颜色 `#7F8C8D`
- **数字/金额**：DIN Alternate Bold，16px，颜色根据正负值变化

### 6.4 圆角与阴影
- **卡片**：圆角 16px，阴影 `0 2px 12px rgba(0,0,0,0.06)`
- **按钮**：圆角 24px（大按钮）/ 12px（小按钮）
- **头像**：圆角 50%（圆形）
- **弹窗**：圆角 20px，阴影 `0 8px 32px rgba(0,0,0,0.12)`

### 6.5 图标风格
- 使用**线性图标**（2px描边），圆角端点
- 主色调填充或描边
- 关键操作图标（如结算、分享）使用面性图标增强识别

## 八、异常处理

### 8.1 网络异常
- 页面加载失败：显示网络异常插画 + "网络开小差了，点击重试"
- 结算提交失败：保留输入数据，提示"提交失败，请重试"，提供重试按钮

### 8.2 业务异常
- 房间号不存在：提示"房间不存在或已解散"
- 房间已满：提示"房间已满员（X/8人）"
- 结算金额不平衡：提示"收支不平衡，请检查各玩家金额"
- 非房主点击结算：提示"只有房主可以结算房间"

### 8.3 权限异常
- 未登录用户：引导登录/注册
- 非房间成员：提示"你不是该房间成员"

## 九、非功能性需求

### 9.1 性能需求
- 页面首屏加载时间 ≤ 2秒
- 结算计算响应时间 ≤ 500ms
- 支持同时在线房间数 ≥ 10000

### 9.2 兼容性
- 支持 iOS 12+ / Android 8+
- 适配 iPhone SE 至 iPhone 16 Pro Max 全系列
- 适配主流安卓机型（华为、小米、OPPO、vivo等）

### 9.3 安全需求
- 房间号6位数字，随机生成，防暴力破解
- 用户数据加密传输（HTTPS）
- 敏感操作（结算）需二次确认
