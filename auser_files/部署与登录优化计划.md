## 一、需求梳理

### 需求 1：简化微信登录流程

**当前问题**：登录页需要用户手动选择头像 + 输入昵称，操作步骤多。

**目标**：用户只需点击"微信登录"按钮，自动获取微信昵称和头像。

**分析**：
- 微信小程序目前获取用户信息的推荐方式：`<button open-type="chooseAvatar">` 获取头像，`<input type="nickname">` 自动填入昵称
- 这两个组件都需要用户交互（至少一次点击），无法完全无感获取
- 最简方案：将头像选择和昵称填入合并到"微信登录"按钮的点击流程中

**涉及文件**：
- `pages/login/login.wxml` — 重构登录页 UI
- `pages/login/login.js` — 移除手动输入逻辑
- `pages/login/login.wxss` — 简化样式
- `services/user.service.js` — 登录接口调整

---

### 需求 2：添加用户协议和隐私政策

**当前问题**：登录页底部已显示"登录即代表同意《用户协议》与《隐私政策》"，但链接不可点击，没有对应页面。

**目标**：创建两个静态页面，编写符合项目实际的内容。

**分析**：
- 用户协议：说明产品功能、用户行为规范、免责条款等
- 隐私政策：说明收集哪些信息、如何使用、如何保护等
- 作为小程序内静态页面，不涉及后端接口

**涉及文件**：
- `pages/agreement/agreement.wxml` + `.wxss` + `.js` + `.json` — 用户协议页
- `pages/privacy/privacy.wxml` + `.wxss` + `.js` + `.json` — 隐私政策页
- `app.json` — 注册新页面
- `pages/login/login.wxml` — 绑定点击跳转

---

### 需求 3：头像存储路径可配置

**当前问题**：头像上传固定存到 `server/uploads/`，与代码混在一起，随用户增多服务端体积膨胀。

**目标**：上传目录路径可配置，不依赖代码部署目录。

**分析**：
- 当前 `server/routes/user.routes.js` 中硬编码 `UPLOAD_DIR = path.join(__dirname, '..', 'uploads')`
- 当前 `server/app.js` 也硬编码 `UPLOAD_DIR = path.join(__dirname, 'uploads')`
- 需要改为从环境变量读取，且默认值放到项目外部（如 `/data/scorekeeper/uploads`）

**涉及文件**：
- `server/.env` — 新增 `UPLOAD_DIR` 配置
- `server/config/env.js` — 读取 `UPLOAD_DIR`
- `server/app.js` — 使用配置的路径
- `server/routes/user.routes.js` — 使用配置的路径

## 二、开发计划

### 步骤 1：头像存储路径可配置

**改动**：

1. `server/.env` 新增：
```env
# 上传文件存储路径（绝对路径，部署时修改）
UPLOAD_DIR=/data/scorekeeper/uploads
```

2. `server/config/env.js` 新增：
```js
uploadDir: process.env.UPLOAD_DIR || path.join(__dirname, '..', 'uploads'),
```

3. `server/routes/user.routes.js`：
   - 引入 `env` 配置
   - 将 `UPLOAD_DIR` 硬编码替换为 `env.uploadDir`

4. `server/app.js`：
   - 将 `UPLOAD_DIR` 硬编码替换为 `env.uploadDir`

---

### 步骤 2：简化登录流程

**改动**：

1. **`login.wxml`** — 移除头像选择按钮、昵称输入框，替换为：
   - 品牌 Logo + 标语
   - "微信登录"大按钮（`open-type="chooseAvatar"`）
   - 底部协议链接

2. **`login.js`** — 简化逻辑：
   - `chooseAvatar` 回调中获取头像临时路径
   - 同时通过 `<input type="nickname">` 自动获取微信昵称
   - 自动调用 `wx.login()` → 后端登录
   - 无需上传头像到服务器，直接使用微信头像临时路径

3. **`login.wxss`** — 精简样式

---

### 步骤 3：创建用户协议和隐私政策页面

**内容**：根据项目实际编写（棋牌计分小程序，用于麻将/棋牌游戏计分）。

**改动**：

1. 新建 `pages/agreement/` 四个文件
2. 新建 `pages/privacy/` 四个文件
3. 在 `app.json` 中注册两个页面
4. 在 `login.wxml` 中绑定点击跳转
