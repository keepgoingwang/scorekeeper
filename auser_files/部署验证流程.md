## 二、后端部署

### 2.1 服务器环境准备

```bash
# 1. 安装 Node.js（推荐 v18 LTS 或 v20 LTS）
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs
node -v    # 应 >= 18

# 2. 安装 MongoDB（如需本机数据库）
# 或使用线上 MongoDB（已配置好 40.108.90.72:27017）
```

### 2.2 部署代码

```bash
# 1. 创建应用目录
mkdir -p /app/scorekeeper

# 2. 上传代码（从本地 git 拉取或 scp 上传）
cd /app/scorekeeper
git clone https://github.com/keepgoingwang/scorekeeper.git .
# 或 scp -r ./server root@你的服务器:/app/scorekeeper/server

# 3. 进入后端目录，安装依赖
cd /app/scorekeeper/server
npm install --production

# 4. 创建上传目录
mkdir -p /data/scorekeeper/uploads/avatars

# 5. 配置环境变量
cp .env .env.production
# 编辑 .env.production 或直接修改 .env
```

### 2.3 配置 `.env`

```env
# 服务端口
PORT=3000

# MongoDB 连接串（线上数据库）
MONGO_URI=mongodb://scorekeeper:md_pwd_scorekeeper@40.108.90.72:27017/scorekeeper

# 上传文件存储根目录（绝对路径，按类型自动分子目录：avatars/ 等）
UPLOAD_DIR=/data/scorekeeper/uploads

# JWT 密钥（生产环境务必修改为随机字符串）
JWT_SECRET=生产环境随机字符串

# 微信小程序 AppID 与 Secret
WX_APP_ID=wx84ad780d9b1d352f
WX_SECRET=你的微信小程序Secret

# 允许跨域来源（小程序无需 CORS，但开发工具联调需要）
CLIENT_ORIGIN=*
```

### 2.4 启动服务

```bash
# 方式一：直接启动（测试用）
cd /app/scorekeeper/server
node app.js

# 方式二：PM2 进程管理（推荐生产用）
npm install -g pm2
pm2 start app.js --name scorekeeper
pm2 save
pm2 startup   # 设置开机自启

# 查看运行状态
pm2 status
pm2 logs scorekeeper
```

### 2.5 配置 Nginx 反向代理（可选但推荐）

```nginx
# /etc/nginx/sites-available/scorekeeper
server {
    listen 80;
    server_name your-domain.com;

    # API 请求
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # WebSocket
    location /ws {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # 静态文件（头像等）
    location /uploads/ {
        alias /data/scorekeeper/uploads/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
}
```

```bash
# 启用站点
ln -s /etc/nginx/sites-available/scorekeeper /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

修改 `utils/constants.util.js`：

```javascript

// export const API_BASE = 'http://localhost:3000';
```

1. **开发管理 → 开发设置 → 服务器域名**

   - `uploadFile合法域名`：`https://your-domain.com`
   - `downloadFile合法域名`：`https://your-domain.com`

2. **版本管理 → 提交审核**（通过微信开发者工具上传代码）

## 四、验证流程

### 4.1 后端验证

```bash
# 1. 验证服务启动
curl http://你的服务器IP:3000/api/user/profile
# 期望返回：{"code":401,"data":null,"message":"未登录"}
#（401 说明服务正常，只是没有 token）

# 2. 验证数据库连接
pm2 logs scorekeeper
# 期望看到：[db] MongoDB connected

# 3. 验证静态文件服务
curl -I http://你的服务器IP:3000/uploads/avatars/
# 期望返回：200 OK（目录可访问）

# 4. 验证 WebSocket
# 使用 wscat 或浏览器控制台
# wscat -c ws://你的服务器IP:3000/ws?token=xxx
# 连接成功无报错即可
```

### 4.2 功能验证

| 测试项 | 步骤 | 预期结果 |
|--------|------|----------|
| **登录** | 打开小程序 → 点击"微信一键登录" → 选择头像 | 自动登录成功，进入首页 |
| **创建房间** | 首页点击"创建房间" | 进入房间页，自动弹出分享弹窗 |
| **加入房间** | 另一台设备扫码或输入房间号 | 成功加入房间，看到双方头像 |
| **手动结算** | 切换到手动模式 → 点击"支出" → 选择收款人 → 输入金额 | 积分正确转移，动态区更新 |
| **自动结算** | 房主点击"结算本局" → 各用户输入收支 → 提交 | 收支平衡时积分更新，不平衡时提示重新输入 |
| **终局结算** | 房主操作菜单 → "房间结算（终局）" | 显示排名和转账方案 |
| **退出房间** | 操作菜单 → "退出房间" | 头像变灰，不再参与结算 |
| **解散房间** | 房主操作菜单 → "解散房间" | 房间解散，所有成员回到首页 |
| **头像上传** | 我的 → 编辑资料 → 更换头像 | 头像上传成功，显示新头像 |

### 4.3 异常场景验证

| 场景 | 操作 | 预期结果 |
|------|------|----------|
| 已在房间内创建新房间 | 在房间内点击首页"创建房间" | 弹出确认弹窗，确认后退出旧房间并入新房间 |
| 房间号不存在 | 输入不存在的房间号 | 提示"房间不存在或已解散" |
| 非房主操作房主功能 | 普通用户点击"解散房间" | 提示"只有房主可以执行此操作" |
| 自动结算收支不平衡 | 用户输入的收入 ≠ 支出 | 提示重新输入，倒计时重置 |
| 手动结算积分不足 | 支出超过当前积分 | 提示"积分不足" |

## 六、常见问题

### 6.1 微信小程序无法请求 API

**原因**：未配置合法域名白名单 或 未使用 HTTPS

**解决**：
1. 确保小程序后台已添加 `https://your-domain.com` 到 request 白名单
2. 生产环境必须使用 HTTPS（不能使用 HTTP）
3. 开发工具中可勾选"不校验合法域名"临时调试

### 6.2 WebSocket 连接失败

**原因**：WSS 需要 HTTPS 证书，或 Nginx 未配置 WebSocket 升级

**解决**：Nginx 配置中必须包含：
```nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

### 6.3 头像上传失败

**原因**：上传目录不存在或权限不足

**解决**：
```bash
mkdir -p /data/scorekeeper/uploads/avatars
chmod 755 /data/scorekeeper/uploads
chown -R www-data:www-data /data/scorekeeper/uploads  # 按 Nginx 用户调整
```

### 6.4 头像 404

**原因**：`express.static` 的路径与 `UPLOAD_DIR` 不一致

**解决**：检查 `app.js` 中：
```javascript
app.use('/uploads', express.static(UPLOAD_DIR));
// UPLOAD_DIR 必须与 .env 中的 UPLOAD_DIR 一致
```

### 6.5 数据库连接失败

**原因**：MongoDB 未启动 或 连接串错误

**解决**：
```bash
# 检查 MongoDB 是否运行
systemctl status mongod

# 测试连接
mongosh mongodb://scorekeeper:md_pwd_scorekeeper@40.108.90.72:27017/scorekeeper
```
