# 牌桌记分 · 常用运维命令

> 在 **server 目录**下运行。所有 `node -e` 命令会自动读取该目录 `.env` 里的 `MONGO_URI`，
> 无需手填连接串，**数据库口令也不会留在 shell history**（这是推荐用 node 方式的理由之一）。

## 使用说明（先看）

- **运行位置**：先 `cd server`，再粘贴命令。
- **引号规则（重要）**：每条命令外层是**单引号**，内部 JS 字符串一律用**双引号**。
  替换占位符时，值也用双引号包，**切勿在命令内部使用单引号**，否则命令会被截断报错。
- **占位符**：`<用户_id>` = 用户列表里的 `_id`；`<房间号>` = 6 位 roomNo；`<openid>` = 微信 openid。
- **写操作**：标 ⚠️ 的为修改/删除，默认走软删或带 `DRY` 开关；执行前先用对应**查询**命令确认目标。
- **环境确认**：命令连的是 `.env` 指向的库（本地 or 线上），跑前确认 `MONGO_URI` 是你要操作的环境。
- 若服务器装了 `mongosh`，文末附录有等价写法（但连接串含口令，粘进终端会留 history，慎用）。

## 一、用户

### 1. 查全部用户（含统计 / 头像路径 / 软删标记 / 注册时间）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const us=await U.find({}).sort({createTime:-1}).lean();console.log("total="+us.length);us.forEach(u=>console.log([u._id.toString(),u.nickname||"-",u.role,u.openid,(u.avatar||"-").slice(0,46),"games="+(u.stats&&u.stats.games||0),"score="+(u.stats&&u.stats.totalScore||0),u.isDeleted?"[DEL]":"",u.createTime?new Date(u.createTime).toLocaleString():""].join(" | ")));await m.disconnect()})()'
```

### 2. 按 _id 查单个用户（完整文档）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const u=await U.findById("<用户_id>").lean();console.log(JSON.stringify(u,null,2));await m.disconnect()})()'
```

### 3. 按 openid 查用户
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const u=await U.findOne({openid:"<openid>"}).lean();console.log(JSON.stringify(u,null,2));await m.disconnect()})()'
```

### 4. 用户统计（总数 / 软删 / 各角色）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const all=await U.countDocuments({});const del=await U.countDocuments({isDeleted:true});const roles=await U.aggregate([{$group:{_id:"$role",n:{$sum:1}}}]);console.log("total="+all+" deleted="+del);roles.forEach(r=>console.log("  role="+r._id+" : "+r.n));await m.disconnect()})()'
```

### 5. ⚠️ 软删除某用户（同时清掉其占用的房间，避免脏数据）
> 先跑命令 2 确认 `_id` 无误。优先软删，不要物理删。
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const id="<用户_id>";const r=await U.updateOne({_id:id,isDeleted:false},{$set:{isDeleted:true,currentRoomId:null}});console.log("soft_deleted modified="+r.modifiedCount);await m.disconnect()})()'
```

### 6. ⚠️ 清除某用户的 currentRoomId（用户“卡在房间里”/无法建房加入时用）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const id="<用户_id>";const r=await U.updateOne({_id:id},{$set:{currentRoomId:null}});console.log("cleared modified="+r.modifiedCount);await m.disconnect()})()'
```

### 7. 头像路径修复：预览（列出 avatar 缺 avatars/ 子目录的用户）
> 真正执行回填用：`npm run migrate:avatars`（脚本会按物理文件位置智能回填，幂等安全）。
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const list=await U.find({avatar:{$regex:"^/uploads/(?!avatars/)"}}).select("nickname avatar").lean();console.log("need_fix="+list.length);list.forEach(u=>console.log("  "+u._id+" "+u.nickname+" "+u.avatar));await m.disconnect()})()'
```

## 二、房间

### 8. 查全部房间（状态 / 模式 / 局数 / 成员数 / 活跃成员数）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const R=require("./models/room.model");(async()=>{await m.connect(env.mongoUri);const rs=await R.find({}).sort({createTime:-1}).lean();console.log("total="+rs.length);rs.forEach(r=>{const act=(r.members||[]).filter(x=>x.status==="active").length;console.log([r.roomNo,r.state,r.mode,"round="+r.round,"members="+(r.members||[]).length,"active="+act,r.isDeleted?"[DEL]":""].join(" | "))});await m.disconnect()})()'
```

### 9. 按房间号查详情（含成员昵称 / 积分 / 房主标记）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const R=require("./models/room.model");(async()=>{await m.connect(env.mongoUri);const r=await R.findOne({roomNo:"<房间号>"}).populate("members.userId","nickname avatar").lean();if(!r){console.log("not found")}else{console.log("roomNo="+r.roomNo+" state="+r.state+" mode="+r.mode+" round="+r.round+" skin="+r.skin);(r.members||[]).forEach(x=>console.log("  - "+(x.userId&&x.userId.nickname||x.userId)+" | "+x.status+" | score="+x.score+(x.isOwner?" [owner]":"")))}await m.disconnect()})()'
```

### 10. 查活跃房间（未解散/未终局 且 未软删）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const R=require("./models/room.model");(async()=>{await m.connect(env.mongoUri);const rs=await R.find({isDeleted:false,state:{$nin:["dissolved","settled"]}}).sort({updateTime:-1}).lean();console.log("active_rooms="+rs.length);rs.forEach(r=>console.log("  "+r.roomNo+" "+r.state+" "+r.mode+" round="+r.round));await m.disconnect()})()'
```

### 11. 查某房间流水
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const R=require("./models/room.model");const F=require("./models/flow.model");(async()=>{await m.connect(env.mongoUri);const r=await R.findOne({roomNo:"<房间号>"}).lean();if(!r){console.log("room not found");await m.disconnect();return}const list=await F.find({roomId:r._id,isDeleted:false}).sort({_id:-1}).lean();console.log("room="+r.roomNo+" flows="+list.length);list.forEach(f=>console.log("  ["+f.type+"] round="+f.round+" amount="+f.amount+(f.memo?(" memo="+f.memo):"")+" "+(f.createTime?new Date(f.createTime).toLocaleString():"")));await m.disconnect()})()'
```

### 12. 查某房间“卡住”的结算单（state 非 done，排查自动结算卡死）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const R=require("./models/room.model");const S=require("./models/settle-round.model");(async()=>{await m.connect(env.mongoUri);const r=await R.findOne({roomNo:"<房间号>"}).lean();if(!r){console.log("room not found");await m.disconnect();return}const list=await S.find({roomId:r._id,state:{$ne:"done"}}).sort({round:-1}).lean();console.log("room="+r.roomNo+" pending_settles="+list.length);list.forEach(s=>console.log("  round="+s.round+" state="+s.state+" balance="+s.balance+" submitted="+s.submissions.filter(x=>x.submitted).length+"/"+s.submissions.length));await m.disconnect()})()'
```

### 13. ⚠️ 强制解散某房间（运维兜底：标记解散 + 清活跃成员的 currentRoomId）
> 正常应走前端“解散房间”；仅当接口不可用或数据卡死时直接用此命令。先跑命令 9 确认成员。
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const R=require("./models/room.model");const U=require("./models/user.model");(async()=>{await m.connect(env.mongoUri);const no="<房间号>";const r=await R.findOne({roomNo:no,isDeleted:false}).lean();if(!r){console.log("room not found");await m.disconnect();return}const ids=(r.members||[]).filter(x=>x.status==="active").map(x=>x.userId);await R.updateOne({_id:r._id},{$set:{isDeleted:true,state:"dissolved"}});const c=await U.updateMany({_id:{$in:ids},currentRoomId:r._id},{$set:{currentRoomId:null}});console.log("dissolved room="+no+" cleared_users="+c.modifiedCount);await m.disconnect()})()'
```

## 三、战绩

### 14. 查某用户战绩概览（聚合：场次 / 胜 / 负 / 平 / 累计分）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const Rec=require("./models/record.model");(async()=>{await m.connect(env.mongoUri);const id="<用户_id>";const a=await Rec.aggregate([{$match:{userId:m.Types.ObjectId(id),isDeleted:false}},{$group:{_id:null,games:{$sum:1},win:{$sum:{$cond:[{$eq:["$result","win"]},1,0]}},lose:{$sum:{$cond:[{$eq:["$result","lose"]},1,0]}},even:{$sum:{$cond:[{$eq:["$result","even"]},1,0]}},total:{$sum:"$score"}}}]);console.log(a[0]||{games:0});await m.disconnect()})()'
```

## 四、总览

### 15. 一键统计（用户 / 房间 / 活跃房间 / 流水 / 战绩）
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");const R=require("./models/room.model");const F=require("./models/flow.model");const Rec=require("./models/record.model");(async()=>{await m.connect(env.mongoUri);const [uAll,uDel,rAll,rAct,fAll,recAll]=await Promise.all([U.countDocuments({}),U.countDocuments({isDeleted:true}),R.countDocuments({}),R.countDocuments({isDeleted:false,state:{$nin:["dissolved","settled"]}}),F.countDocuments({isDeleted:false}),Rec.countDocuments({isDeleted:false})]);console.log("users="+uAll+" (deleted="+uDel+")");console.log("rooms="+rAll+" active="+rAct);console.log("flows="+fAll+" records="+recAll);await m.disconnect()})()'
```

## 五、危险区（默认不执行，带 DRY 开关）

### 16. 物理删除全部已软删用户（默认 DRY=true 只预览，确认数量后改 DRY=false 再跑）
> ⚠️ 不可逆。一般无需物理删，软删即可。
```bash
node -e 'const env=require("./config/env");const m=require("mongoose");const U=require("./models/user.model");(async()=>{const DRY=true;await m.connect(env.mongoUri);const ids=await U.find({isDeleted:true}).select("_id").lean();console.log("will_delete="+ids.length);if(DRY){console.log("DRY run, nothing deleted. set DRY=false to execute")}else{const r=await U.deleteMany({isDeleted:true});console.log("deleted="+r.deletedCount)}await m.disconnect()})()'
```

## 附录：若已安装 mongosh（等价写法）

> 连接串含口令，粘进终端会留在 history；用完可 `history -d <行号>` 删除，或优先用上面的 node 命令。
> 把 `<MONGO_URI>` 换成 `.env` 里 `MONGO_URI` 的值。

```bash
# 进入交互 shell
mongosh "<MONGO_URI>"

# 在 shell 内常用：
db.users.find({},{openid:1,nickname:1,avatar:1,role:1,stats:1,isDeleted:1,createTime:1}).sort({createTime:-1}).forEach(u=>printjson(u))
db.users.countDocuments({})
db.rooms.findOne({roomNo:"<房间号>"})
db.flows.find({roomId: ObjectId("<roomId>"), isDeleted:false}).sort({_id:-1}).forEach(f=>printjson(f))
```
